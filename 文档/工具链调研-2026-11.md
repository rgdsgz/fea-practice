# 免费 / 开源「选材 → 建模 → 网格 → 有限元」工具链调研

> 调研时间：2026-11-11 ｜ 目标机器：Windows 11，已装 FreeCAD 1.1.4，网络在中国大陆
> 结论只推荐**免费**工具：优先开源；闭源免费方案（Ansys Student、SimScale、Z88Aurora）作为备选并标注限制。

---

## 0. 一句话结论

**主推组合：FreeCAD 1.1.4（建模 + 网格 + 求解）+ CalculiX（求解器，FreeCAD 已内置 2.22）+ 自建 SQLite/Ashby 选材库（用 FreeCAD 自带 125 张材料卡做底库）。**
你机器上**零安装**就能跑通「建模 → 网格 → 线性静力/模态/热/接触」闭环；想要更好的前后处理体验再装 **PrePoMax 3.0.0**（201 MB，Windows 绿色版，实测可直连下载）。
只有需要**非线性、疲劳、断裂、多物理**时，才值得上 WSL2 + **Salome-Meca / Code_Aster** 或 **Elmer**。

## 2. 四个环节的候选与取舍

### 2.1 选材（现状：没有免费的「Ashby 级」成品，必须自建）

| 方案 | 链接 | 免费/许可 | 能提供什么 | 坑 |
|---|---|---|---|---|
| FreeCAD 材料卡 | 本机 `F:\FreeCAD\data\Mod\Material` | LGPL / CC | 125 张标准材料（金属、塑料等），**可直接被 FEM 使用** | 牌号少、无成本/工艺属性 |
| MatWeb | https://www.matweb.com | 免费注册查看；条款禁止抓取/再分发 | 牌号级 ρ、E、σy、σb、CTE、k，工程最全 | 无 API；批量需授权；国内直连有反爬 |
| Engineering Toolbox | https://www.engineeringtoolbox.com | 免费（广告） | 常用材料典型值速查 | 无牌号、来源笼统 |
| NIST Materials Data | https://materialsdata.nist.gov | 免费，有 API | 权威科研数据集 | 数据零散，非手册值 |
| Materials Project | https://materialsproject.org | 免费 API key；数据 CC BY 4.0 | DFT 弹性张量（可推 E、ν） | **不能代替工程牌号强度**，仅趋势参考 |
| pymatgen / matminer | https://github.com/materialsproject/pymatgen | MIT / 开源 | 批量取 MP 数据 | 面向材料信息学，不是选材工具 |
| 国家新材料大数据中心 | https://www.matbd.cn | 公益免费（注册） | 国内直连、数据集 | 偏科研，牌号力学数据少 |
| Granta EduPack | https://ansys.synopsys.com/products/materials/granta-edupack | **商业**，仅高校授权 | Ashby 图 + 材料指数选材，最完整 | 无个人免费版，数据不可导出 |
| Ashby 图开源实现 | [walgren/Ashby-plots](https://github.com/walgren/Ashby-plots)（MIT，6★）；[slehmann1/OpenAshby](https://github.com/slehmann1/OpenAshby)（无许可证，17★，已停更）；[alexiamlee/OpenAshbyPlot](https://github.com/alexiamlee/OpenAshbyPlot)（MIT）；[Neburok/ashby-chart-selector](https://github.com/Neburok/ashby-chart-selector) | MIT / 无许可 | matplotlib 画包络图 + 材料指数线 | 只给画图代码，**数据要自己填** |

**建议做法（可落地）**

1. 建 `materials.db`（SQLite）：`材料 / 牌号 / 标准 / ρ / E / ν / σy / σb / δ / CTE / k / 价格 / 来源 / 许可 / 录入日期`。
2. 底库直接导入 FreeCAD 的 125 张 `.FCMat`（Python 解析 JSON 即可），再按厂商 datasheet、MatWeb 手工补牌号。
3. 用 FreeCAD 自带 Python（pandas + matplotlib）画 Ashby 图：E–ρ、σy–ρ、E^0.5/ρ 等指数线；模板可参考 `walgren/Ashby-plots`（MIT 可商用）。
4. 选中的材料**导出成 `.FCMat`** → FreeCAD FEM 直接引用，形成「选材 → 分析」闭环。
5. 合规：MatWeb/手册数据只做内部参考，标注来源；不要批量抓取、不要再分发受版权数据。

## 3. 推荐的三条路线

### 路线 A：最省事、今天就能跑（推荐先走这条）

```
FreeCAD 建模（PartDesign / Assembly）
   → FEM 工作台：Gmsh 网格 → 材料（.FCMat）→ 边界条件 → CalculiX 求解 → 云图
```
- 全程一个软件，零安装、零配置（CalculiX/Gmsh 已内置）。
- 适合：静力强度校核、模态、稳态热、简单接触。
- 学习成本：低；一天的官方教程即可跑通悬臂梁/支架。

### 路线 B：想要更专业的 FEA 体验（建议同时装）

```
FreeCAD 建模 → 导出 STEP → PrePoMax 3.0.0（自带 Gmsh + CalculiX）
```
- PrePoMax 的边界条件、接触、后处理、结果云图/切片比 FreeCAD FEM 顺手得多，教程和社区活跃。
- 下载实测：`https://prepomax.fs.um.si/Files/Downloads/PrePoMax%20v3.0.0.zip`（**201 MB，HTTP 200，1.4 s**）。
- 小优化：把 PrePoMax 的 `Solver` 目录替换成 CalculiX **2.23**（http://www.dhondt.de/ 的 `calculix_2.23_4win.zip`）。
- 适合：非线性、接触、批量化分析。

### 路线 C：进阶（按需再上，别一开始就折腾）

- **非线性 / 接触 / 疲劳 / 断裂 / 抗震** → WSL2 + **Salome-Meca 2025**（含 Code_Aster），Linux 原生、能力最强；代价是 2–3 GB 下载 + 陡峭学习曲线。
- **多物理（热-流-固、电磁）** → **Elmer 26.2.1**。
- **自定义 PDE / 科研脚本** → **FEniCSx 0.11**（WSL2/Docker）。
- **零安装、临时算一算** → **SimScale** 免费社区版（注意项目公开）或 **Ansys Student**（32k 节点）。

## 5. 建议的落地顺序（一周内跑通）

1. **第 1 天**：FreeCAD FEM 官方教程跑一遍（悬臂梁），确认单位制：**mm-N-MPa**（或 m-N-Pa），单位错是新手第一大坑。
2. **第 2 天**：做一个自己的零件：建模 → Gmsh 网格 → 材料（先选 FreeCAD 材料卡里的 Steel/Aluminum）→ 固定 + 载荷 → 求解 → 看 von Mises。
3. **第 3 天**：**网格收敛性验证**：同一模型加密 2–3 次，看最大应力是否收敛（这是判断结果可不可信的唯一标准）。
4. **第 4 天**：装 PrePoMax，把同一个模型做一遍，对比结果（两个前端应给出接近的数值）。
5. **第 5 天**：搭选材库：解析 125 张 `.FCMat` 入 SQLite → 画 E–ρ、σy–ρ Ashby 图 → 补 3–5 个你常用的牌号。
6. **第 6–7 天**：把「选材 → .FCMat → FEM」串成 FreeCAD 宏或脚本，重复分析自动化。

校验小技巧：悬臂梁端部挠度理论解 `δ = FL³/(3EI)`，FEA 结果应在 5% 以内（细网格）。

## 6. 需要你确认的 4 个问题（决定最终选型）

1. **分析对象**是什么？（金属结构件 / 塑料件 / 复合材料 / 土建结构？）
2. 需要哪些**分析类型**？（静力 / 模态 / 热 / 接触非线性 / 疲劳 / 冲击 / CFD？）
3. 能否接受 **WSL2 / Linux**？（决定要不要上 Code_Aster；不能接受就锁定 FreeCAD+CalculiX+PrePoMax）
4. 是否需要**参数化批量/优化**（决定要不要写 Python 脚本 + FEMbyGEN/PrePoMax API）？

## 8. 针对你的需求的最终方案（金属为主 / 塑料为辅 · 静力 + 接触非线性 + 疲劳 · Windows 原生）

### 8.1 选型（最终版）

| 环节 | 工具 | 版本 | 为什么选它 |
|---|---|---|---|
| 建模 | **FreeCAD 1.1.4**（已装）+ 插件 fasteners / parts_library / sheetmetal | 1.1.4 | 参数化 + STEP 互通；插件管理器已修好可直接装 |
| 网格 | **Gmsh 4.15 / Netgen**（PrePoMax 与 FreeCAD 都内置） | 4.15 | 四面体自动网格质量够用；六面体用 PrePoMax 内置映射网格 |
| 前处理 + 求解（静力/接触非线性） | **PrePoMax 3.0.0** + **CalculiX 2.23** | 3.0.0 / 2.23 | 接触（含摩擦/绑定/仅受压/刚体参考点）、几何+材料非线性、静力/模态/屈曲/热/动态；免费里前后处理最好 |
| 疲劳 | **Python 后处理链路**：fatpack（ISC）/ boschresearch/pylife（Apache-2.0）/ rainflow（MIT）+ ccx2paraview（GPL-3.0） | 最新 | **Windows 上没有免费的疲劳 GUI**，这条是唯一全免费可编程路线（见 8.4） |
| 选材 | SQLite + Python(FreeCAD 自带 pandas/scipy/matplotlib) + Ashby 图 | — | 见第 2.1 节；FreeCAD 125 张材料卡做底库 |
| 备选疲劳 GUI | Ansys Student（免费闭源，32k 节点上限，Fatigue Tool） | 学生版 | 不想写 Python 时的备胎；非开源、有限制 |

> **为什么不用 FreeCAD FEM 做主求解器**：它能做静力和简单接触，但接触设置、收敛控制、后处理都弱于 PrePoMax；建议 FreeCAD 只负责建模，FEA 全部放 PrePoMax。计算器仍是同一个 CalculiX，结果格式一致（.frd）。

### 8.2 安装清单（按顺序，约 1 小时）

1. **PrePoMax 3.0.0**：下载 `https://prepomax.fs.um.si/Files/Downloads/PrePoMax v3.0.0.zip`（201 MB，实测直连 1.4 s 响应），解压到 **非系统目录**（建议 `D:\E\Model\tools\PrePoMax`），运行 `PrePoMax.exe`。依赖 .NET Framework 4.8（Windows 11 自带）。

### 8.3 分析流程：静力 + 接触非线性

```
FreeCAD 建模（零件/装配） → 导出 STEP
   → PrePoMax：导入 STEP → 材料（E/ν/塑性） → 定义接触对
   → 约束/载荷 → Gmsh 网格（接触区局部加密） → 求解
   → 后处理：von Mises、接触压力、穿透量；做 2–3 次网格加密验证收敛
```

要点：
- **接触**：面-面接触 + 摩擦系数；初始间隙要留（否则刚体位移/不收敛）；接触刚度先用默认，收敛困难时降刚度或加密接触面网格。
- **网格收敛**：接触压力对网格敏感，至少做 2 级加密，看最大接触压力是否稳定。
- **单位制**：PrePoMax 支持 mm-N-MPa（推荐），建模与材料数据保持同一套。

### 8.4 疲劳流程（高周 S-N，恒幅 / 变幅都支持）

Windows 原生、全免费的实现方式：

```
PrePoMax 求解 → 结果 .frd → ccx2paraview 转 .vtu
   → Python：读节点应力张量 → 等效应力幅 σa（von Mises 幅值 / 临界平面）
   → 平均应力修正（Goodman / Gerber / SWT）
   → 材料 S-N 曲线：σa = σf'·(2N)^b 或工程近似
   → Miner 损伤累积 D = Σ n_i/N_i，寿命 N = 1/D
   → matplotlib 输出：寿命云图 + 最危险点报告
```

具体做法：
1. **恒幅载荷**：从静力结果取危险点应力幅 σa 和平均应力 σm，直接查 S-N → N。
2. **变幅载荷**：把载荷-时间序列用 `rainflow`（MIT）做雨流计数 → 得到 (σa_i, n_i) 各级 → 逐级算 N_i → Miner 求和。
3. **材料 S-N 参数**（金属）：
   - 钢材工程估算（Shigley）：S_e = 0.5·S_ut（S_ut<1400 MPa）再乘表面/尺寸/载荷等修正；S_1000 = 0.9·S_ut；Basquin 参数 `a=(f·S_ut)²/S_e`，`b=-(1/3)·log10(f·S_ut/S_e)`（f≈0.9）。
   - 铝合金：**没有真正的疲劳极限**，用 5×10⁸ 循环对应强度。
   - 有实测 S-N 数据时（厂商/文献）优先用实测，别用估算。
4. **接触部位的疲劳**：分别算「最大载荷」和「最小载荷」两个静力工况 → 应力差即应力幅；接触状态在两种载荷下可能变化，必须两个状态都收敛后再做差。
5. **塑料**：S-N 数据少且对温度/频率/蠕变敏感；优先用厂商 datasheet 的 S-N 曲线，无数据时只能做定性评估，**不要用钢材估算公式**。

### 8.5 材料数据（金属 + 塑料）

| 类别 | 需要字段 | 免费来源 |
|---|---|---|
| 金属 | E、ν、ρ、σy、σb、S-N（σf'、b、Se） | 厂商 datasheet（最可信）、MatWeb 手工录入、Shigley 估算公式、FreeCAD 材料卡 |
| 塑料 | E、ν、σy、S-N、长期蠕变数据 | **CAMPUS**（https://www.campusplastics.com/campus/en，免费塑料材料库）、厂商 datasheet、MatWeb |
| 选材 | 成本/工艺/密度 | 自建 SQLite，见 2.1；Ashby 图用 `walgren/Ashby-plots`（MIT）当模板 |

### 8.6 局限与风险（提前知道）

1. **没有免费的疲劳 GUI**：疲劳云图要自己用 Python 画，这是本方案最大的"工作量点"；不接受就退到 Ansys Student。
2. **塑料的黏弹性/蠕变**：PrePoMax 的材料模型只有线弹性 + 弹塑性（各向同性/随动硬化，可随温度），**不支持黏弹性/蠕变**；塑料只做弹性/弹塑性近似，长期行为算不了。
3. **接触 + 疲劳** 是坑最多组合：先保证接触收敛，再做疲劳；接触区应力集中对网格极敏感。
4. **疲劳结果的不确定性**：S-N 数据离散性大（±2 倍寿命很常见），结果只能做相对比较和初步筛选，关键件要试验验证。

### 8.7 建议的执行顺序

1. 装 PrePoMax + 升级 CalculiX 2.23（30 分钟）
2. 用「带孔板拉伸」跑通：建模 → STEP → PrePoMax → 静力 → 与理论 Kt 对比（1 天）
3. 做一个**螺栓/销轴接触**算例，跑通接触非线性（1–2 天）
4. 写疲劳脚本：先用悬臂梁恒幅算例验证（理论 Basquin + Miner 手算）（1 天）
5. 串起来：接触工况两载荷步 → 应力差 → 疲劳评定 → 出报告

### 10.3 blueCFD 静默安装的坑（重点）

Inno Setup 安装器，manifest 是 `asInvoker`（不需要 UAC），官方 wiki 给出 `/DIR=`、`/TYPE=custom`、`/COMPONENTS=`、`/TASKS=`、`/VERYSILENT`、`/SINGLEUSER=1`、`/LOG=`。

**失败现象**：直接 `Start-Process -Wait` 拉起，`/VERYSILENT /SUPPRESSMSGBOXES /NORESTART /DIR=F:\blueCFD-Core /LOG=...` 跑完 → 进程一闪而过、无日志、无安装目录、cmd 里 `%ERRORLEVEL%` 还是 0。连试三次都一样。

**真正的解法**（实测成功）：
1. 把 **`$env:TMP`/`$env:TEMP` 指到非 C 盘**（如 `D:\E\Model\tools\tmp\itmp`）——安装器默认往 `%TEMP%`（本机 C 盘）解包 1 GB+ 临时文件，那一步失败时静默退出且不写日志；
2. 用 `Start-Process -RedirectStandardOutput/-RedirectStandardError` 重定向标准流（否则安装器子进程继承管道句柄，pwsh 调用**永远不返回**，看起来像卡死）；
3. 加 `/LOG=<非 C 盘路径>` 才能看到逐文件进度。

改完之后立刻正常：约 5–8 分钟、落盘 3.2 GB / 8.9 万文件、安装到 `F:\blueCFD-Core`（含 `msys64\`、`OpenFOAM-12\`）。

**中止时**：`Stop-Process` 杀掉安装器，Inno 会自己回滚已装文件，`F:\blueCFD-Core` 被清空，无残留。
