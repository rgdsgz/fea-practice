## 新算例怎么加

1. 在 `算例\` 下建目录，放入 `.geo` / `.inp` / 求解脚本 / `README.md`（写清几何、边界、载荷、预期结果）。
2. 用 `tools\regression_test.ps1` 或单独脚本能一键复现。
3. 把基线数值登记到 `AGENTS.md` §5 和本表。
