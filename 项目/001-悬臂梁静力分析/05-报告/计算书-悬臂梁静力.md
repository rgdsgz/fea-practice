## 1. 目的与算例定义

用一个有解析解的经典算例，验证「FreeCAD 选材 → 建模 → 网格 → 有限元 → 后处理」全流程与工具链的正确性，并作为后续项目的模板。

- 几何：矩形截面悬臂梁，长 L = 100 mm，宽 b = 10 mm，高 h = 10 mm
- 材料：CalculiX-Steel（FreeCAD 材料库 Standard/Metal/Steel）
- 约束：左端面 x = 0 全固定（Ux = Uy = Uz = 0）
- 载荷：右端面 x = 100 施加 100 N 集中力，方向 −Z
- 输出：自由端挠度、沿梁长弯曲应力、固定端最大应力

## 4. 边界条件与载荷

| 项目 | 位置 | 数值/定义 |
|---|---|---|
| 固定约束 `ConstraintFixed` | 面 x = 0（Box:Face1） | 全部自由度固定（291 个 SPC = 97 节点 × 3） |
| 力载荷 `ConstraintForce` | 面 x = 100（Box:Face2） | **100 N**，方向 (0, 0, −1) |
| 载荷分布 | 加载面 97 个节点 | 平均每节点 1.031 N（CalculiX 自动均分，97 个集中力） |

> **踩坑记录**：FreeCAD 1.1 的力方向 `Direction` 是 **PropertyLinkSub**（指向一条边并配 `Reversed` 布尔），不是三维向量。GUI 的"方向"输入框不能填 `(0,0,-1)`（会报 Invalid syntax）；正确做法见 §8。

### 交叉验证（CalculiX 2.22 vs 2.23）

同一 `.inp` 分别用 FreeCAD 自带 ccx 2.22 与 PrePoMax 内置 ccx 2.23 求解，**结果完全一致**（挠度 0.190431 mm、应力 30.025/30.038/59.309 MPa 完全相同，.frd 文件仅差 1 字节）。说明替换到 2.23 后求解器行为不变，见 `04-结果\交叉验证-CalculiX223.txt`。

## 7. 讨论

1. **固定端应力略低于理论（−1.2%）**：CalculiX 的节点应力由单元积分点外推并做节点平均，固定端面节点受全约束影响，外推值略偏小；全场最大值 60.88 MPa 出现在固定端附近内部积分点，与理论 60 MPa 吻合。梁理论在 x=0 处本身有边界层效应，工程上取跨中/等效应力判断更稳。
2. **FreeCAD 1.1 后处理单位**：结果面板按 **SI 基本单位**显示（位移 m、应力 Pa），与模型单位（mm、MPa）不同。读色标时换算：1.910e-04 m = 0.1910 mm；6.088e+07 Pa = 60.88 MPa。这不影响 `.frd` 中的数值（mm、MPa）。
3. **力方向输入**：见 §8 踩坑；用 Python 控制台设 `Direction=(object, ["Edge1"])` + `Reversed=True` 是当前 1.1.4 的可行做法。
4. **网格**：二次四面体在弯曲问题中无明显剪切锁死；若改用一次单元需显著加密。

## 8. 复现步骤

### 8.1 FreeCAD GUI 全流程（本次做法）

1. Part 工作台 → 立方体：Length=100、Width=10、Height=10 mm，保存为 `01-几何\悬臂梁.FCStd`。
2. 切 FEM 工作台 → 模型 → 分析容器。
3. 模型 → 材料 → 材料（固体） → Standard → Metal → Steel → **CalculiX-Steel**，OK。
4. 网格 → FEM 网格 → 用 Gmsh 生成：单元维度 From Shape、单元阶次 **2nd**、最大 3.00 mm、最小 0.50 mm → Apply。
5. 视图里先选中左端面 → 模型 → 约束 → **固定边界条件**。
6. 先选中右端面 → 模型 → 约束 → **力载荷**：Force=100 N；方向用 Python 控制台设置（见下）。
7. 模型 → 求解器 → **求解器 CalculiX**；工作目录改为 `03-计算\`；写入 inp → 运行 CalculiX。
8. 双击 `Pipeline_CCX_Results` → 模式 Surface，场 Displacement → 组件 Magnitude；场 **von Mises Stress**。

力方向修复命令（在 Python 控制台执行，`o` 为 Box 对象）：

```python
o = App.ActiveDocument.getObject("立方体")
cf = App.ActiveDocument.ConstraintForce
cf.Direction = (o, ["Edge1"])   # Edge1 为 z 向竖直边（同 x,y、z 差 10）
cf.Reversed = True              # 指向 -Z
App.ActiveDocument.recompute()
```
