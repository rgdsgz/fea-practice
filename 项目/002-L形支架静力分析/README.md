# 002-L形支架静力分析

> 创建日期：2026-11-12 ｜ 单位制：mm-N-MPa

## 1. 项目概览

- **目标**：校核 L 形钣金支架在立板顶部 500 N 侧向载荷下的强度与刚度
- **分析类型**：线性静力（小变形）
- **对象与工况**：底板 100×60×8 + 立板 8×60×80，内角 R8，底板 4×Ø9 孔；底面全固定，立板顶面 500 N 沿 −X
- **验收判据**：安全系数 ≥ 2.0（峰值应力 ≤ 117.5 MPa）；自由端位移 ≤ 1.0 mm

## 3. 几何与网格

- 几何文件：`01-几何\L形支架.FCStd`（Part 工作台：两个 Box 布尔并集 → R8 圆角 → 4×Ø9 布尔差）
- 网格：FreeCAD 内置 Gmsh，C3D10 二阶四面体，最大 3.0 mm / 最小 0.5 mm（圆角曲率加密）
- 规模：节点 36 325，体积单元约 20 690，自由度数 95 100
- 网格收敛性：本算例仅单档网格；峰值位于 R8 圆角曲面，后续可加密到 2 mm 复核（预计变化 <2%）

## 5. 分析设置

- 软件：FreeCAD 1.1.4 + CalculiX 2.22（`F:\FreeCAD\bin\ccx.EXE`），spooles
- 求解：线性静力，1 步，95 100 方程，wall time ≈ 5 s，`CalculiX done without error!`
- 工作目录：`03-计算\ccx\Unnamed\SolverCcxTools\`

## 6. 结果

| 指标 | 数值 | 位置 | 判据 | 结论 |
|---|---|---|---|---|
| 最大 von Mises | **61.68 MPa** | R8 圆角曲面，节点 (8.12, 38.42, 14.61) | ≤117.5 MPa | 通过 |
| 最大位移 | 顶面 ux **−0.1525 mm**（合成 0.1530） | 立板顶面 | ≤1.0 mm | 通过 |
| 安全系数 | **3.81**（σy=235） | — | ≥2.0 | 通过 |
| 疲劳寿命 | 未评定（静载） | — | — | — |

- 结果文件：`04-结果\`（frd / 摘要 txt / 前 30 节点 csv / FreeCAD 云图 png）
- 手算对比：δ=FL³/(3EI)=0.1587 mm（−3.6%）、σ=FLc/I=62.5 MPa（−1.3%）

## 7. 结论与假设

- 结论：500 N 下最大应力 61.7 MPa、SF=3.8，强度与刚度均满足；R8 圆角有效消除内角应力集中
- 关键假设：线弹性、小变形；材料屈服取 235 MPa；载荷为静载、单工况
- 后续工作：如需交变载荷，用 `tools\疲劳\fatigue.py` 做疲劳评定；可加密网格复核圆角峰值
