# 003 — 带孔板应力集中与网格收敛（静力练习）

- 日期：2026-11-14
- 分析类型：线性静力（小变形）
- 单位制：**mm–N–MPa**
- 目的：练「手工建模 → 网格控制 → 局部加密 → 网格收敛判定 → 与理论 Kt 对比」这一整套，为以后复杂件打基础。

## 1. 算例定义

| 项目 | 数值 |
|---|---|
| 板 | 长 120 (Y) × 宽 50 (X) × 厚 10 (Z) |
| 孔 | 中心 Ø16 通孔（轴向 Z），圆心在 (25, 60, 5) |
| 材料 | CalculiX-Steel：E = 210 000 MPa，ν = 0.30，ρ = 7900 kg/m³ |
| 约束 | 底面 y = 0 全固定（ux = uy = uz = 0） |
| 载荷 | 顶面 y = 120，合计 **10 000 N**，沿 **+Y** |

## 2. 理论对照值（用来判对错）

| 量 | 公式 | 结果 |
|---|---|---|
| 净截面宽度 | W − d = 50 − 16 | 34 mm |
| 净截面应力 | σ_nom = F / [(W−d)·t] = 10000 / (34×10) | **29.41 MPa** |
| 应力集中系数（净截面，Howland） | Kt = 2 + (1 − d/W)³ = 2 + (1 − 0.32)³ | **2.31** |
| 孔边最大应力 | σ_max = Kt · σ_nom = 2.31 × 29.41 | **≈ 68 MPa** |

> 只要孔边最大应力落在 66–70 MPa、Kt 落在 2.2–2.4，就算对上了。

## 3. 网格方案（本项目的重点）

四档网格，其余设置完全相同，只改网格尺寸：

| 档 | 全局最大尺寸 | 孔边局部尺寸 | 预期单元数 |
|---|---|---|---|
| 粗 | 6 mm | －（不加密） | 几千 |
| 中 | 4 mm | 1.0 mm | 1–2 万 |
| 细 | 2.5 mm | 0.5 mm | 3–5 万 |
| 很细 | 1.5 mm | 0.3 mm | 8–12 万 |

判据：**σ_max 随网格加密的相对变化 < 2%** 即认为收敛。收敛后取最细两档的平均值作为结论值。
